Smart Car Door Locking & Fault Tolerance System

Overview Link to heading

A real-time embedded safety and security system designed for automotive applications. Built on a multi-tasking RTOS architecture, the system actively monitors vehicle speed, physical door states, and environmental hazards to automate cabin locking. It behaves as a fail-safe critical system — providing passenger convenience during normal operation and triggering immediate, deterministic evacuation protocols during emergencies like crashes or fires.

My Role Link to heading

  • Firmware Engineering: Developed the core application code in C on top of the STM32 Hardware Abstraction Layer (HAL) for reliable, low-level peripheral control.
  • RTOS Architecture: Architected a multi-threaded system using FreeRTOS, managing seven concurrent tasks with strict priority leveling so that critical safety sensors (fire / crash) preempt lower-priority convenience features (auto-locking).
  • State Machine Design: Implemented complex finite-state logic for conditional auto-locking — speed-dependent locking, physical door-open overrides, and ignition-dependent transitions.
  • Hardware Integration: Interfaced digital and analog inputs (IR sensors, crash and fire triggers) and integrated an I2C LCD for real-time system status and emergency driver notifications.

Impact Link to heading

  • Deterministic Safety: The emergency override system automatically unlocks the doors and triggers alarms within milliseconds of a detected crash or fire.
  • Automated Vehicle Security: Removed the need for manual driver intervention through an intelligent auto-lock/unlock system dependent on engine state, physical door clearance, and high/low speed toggles.
  • Scalable Embedded Design: Modular, hardware-agnostic codebase built on HAL and FreeRTOS, so the logic can be ported to different microcontrollers or extended with additional automotive sensors.

Hardware Link to heading

  • STM32F446RE microcontroller
  • STM32 HAL + FreeRTOS
  • IR sensors, crash trigger, fire trigger
  • I2C LCD display
